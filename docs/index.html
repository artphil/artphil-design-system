Links

.ap-link restores the underline the reset removes and takes its color from --ap-link-color. The underline is softened, and turns solid on hover and focus.

Default link Standalone Inherited color

--standalone holds the underline back until interaction. It is for links outside running text — navigation, footers, card actions — where position already tells the link apart.

Inside running text, a link keeps the line height and sits on the same baseline as its paragraph.
